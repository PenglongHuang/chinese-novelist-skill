# 章节摘要模板

规划时按 `02-写作计划.json` 的章号顺序展开全部章节。章号至少两位、标题与计划一致；替换 `{XX}` 和 `{标题}`，三个栏目初始留空，不预写剧情。

```markdown
# 章节摘要

## 第{XX}章 {标题}

### 关键事件与后果

### 人物当前处境

### 行动条件与未了事项
```

## 填写

每章检查、润色后，先读取本章小节，再用 Edit 填写原位，保留标题和栏目，不追加同章副本。改稿同步更新原摘要。批次暂存文件使用相同结构，仅包含本批章节。

- **关键事件与后果**：必须填写，记录正文已发生的事件及其造成的变化；关键变化注明来源场景，不复述大纲或空泛概括。
- **人物当前处境**：保留影响后文的认知、误判、打算、已采取的行动及未消解的情绪关系；不把计划写成已经行动。
- **行动条件与未了事项**：保留后续必需的时间、位置、伤势、物品归属、承诺及伏笔；长期事实可引用词典。

每章合计约 300–500 字，只记正文确立的事实，未确定处标“未明”。后两栏无新增时可简写或引用此前章号，不凑字。

写前只读取已有内容的摘要；空壳、缺项或冲突回查相关正文。空栏目、注释和“待补充”等占位不算有效摘要，也不满足 completed 门槛。并行编辑与正式汇总见 [chapter-state.md](../flows/chapter-state.md)。
