# 章节摘要模板

规划时按 `02-写作计划.json` 的章号顺序展开全部章节。章号至少两位、标题与计划一致；替换 `{XX}` 和 `{标题}`，标题下留空，不预写剧情。

```markdown
# 章节摘要

## 第{XX}章 {标题}

```

## 填写

每章检查、润色后，先读取本章小节，再用 Edit 在标题下写一到数段摘要，不设固定分栏、不追加同章副本。改稿更新原摘要。批次暂存文件使用相同结构，仅包含本批章节。

约 300–500 字，写清正文发生的关键事件及后果，保留影响后续的人物变化、行动条件和未了事项。不把打算写成已经行动；只记正文确立的事实，未确定处标“未明”，长期事实可引用词典。不逐项凑字段。

写前只读取已有内容的摘要；空壳、缺项或冲突回查相关正文。空标题、注释和“待补充”等占位不算有效摘要，也不满足完成门槛。并行编辑与正式汇总见 [phase3-writing.md](../flows/phase3-writing.md#并行写入协议)。
