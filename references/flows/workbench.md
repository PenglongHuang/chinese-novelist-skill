# 本地只读小说书房

## 入口

- 用户说“查看已有小说”“打开小说工作台/书房”：直接打开，只读浏览；跳过偏好加载/更新、创作问答和续写确认。不创建新作品。
- Phase 2 已生成准备资料：在展示规划摘要时启动书房供阅读，仍在 Agent 对话中确认规划和选择写作模式。查看页面不等于同意开始写作。
- 用户显式指定的工作区优先；否则以**当前工作目录**下的 `chinese-novelist/` 为作品集合目录。也可指定单部小说目录。禁止扫描其他磁盘寻找作品。

## 启动

从 SKILL.md 所在位置确定 `{skillBaseDir}`，用该安装目录的绝对路径调用，不要从用户目录执行相对路径 `scripts/workbench.mjs`。

```bash
node "{skillBaseDir}/scripts/workbench.mjs" --workspace "{作品集合目录绝对路径}"
```

例如 skill 安装在 `C:/Skills/chinese-novelist`，用户在 `D:/Writing`：

```bash
node "C:/Skills/chinese-novelist/scripts/workbench.mjs" --workspace "D:/Writing/chinese-novelist"
```

运行时需要 Node.js >=16，无需 npm install、构建、API Key 或外部 CDN。使用宿主环境支持的长驻进程/后台终端机制保持服务；Windows 若使用 Start-Process，必须加 `-WindowStyle Hidden`。保留输出日志，读取实际打印的 `http://127.0.0.1:端口/` 地址，提供可点击链接并在宿主支持时打开浏览器。不能假设固定端口或凭空拼地址。

作品集合下的直接子目录会被发现；无计划的旧作品也可通过编号资料和章节文件识别。首次打开是全部作品书架，点击书名进入作品。可用 `/api/projects` 获取项目 ID，以 `#/projects/<id>/outline` 深链接进入新生成的小说；不要用书名猜 ID。

服务只在本机监听。页面仅阅读文件，不具有编辑、改稿、暂停写作或向 Agent 发任务的能力。

## 文件变化与恢复

- 新作品、章节和元数据自动发现。当前正在读的文档变化时提示“此文档已更新”，用户点击后再载入，避免阅读中跳动。
- 章节进度与字数来自写作计划，并不代表已重新校验或通过作者审定。缺失和损坏资料会显示提示，不会被工作台修复。
- 关闭网页不等于关闭服务。Agent 结束后服务是否仍存活取决于宿主进程机制；不能承诺永久运行。
- 用户在终端用 Ctrl+C 停止服务；需要释放后台服务时只终止本次启动记录对应的进程，不按名称结束所有 Node 进程。
- 断线后页面自动尝试重连，也显示重启命令。使用同一个 `--port` 重启可恢复原标签页；端口已占用时用 `--port 0` 分配新端口并打开新地址。
- 作品目录尚不存在时显示空书架，不创建目录；后续创建会自动发现。
- Node 不可用时说明需要安装 Node，并提供命令供用户之后执行。若宿主无法维持后台服务，提供启动命令，由用户在本地终端运行。不要把启动失败当成作品校验失败。
